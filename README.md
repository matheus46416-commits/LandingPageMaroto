# LandingPageMaroto
Landing Page co-op mode
Centralizar a div foi uma guerra silenciosa,
travada em linhas, margens, pixels e suor,
enquanto o display: flex prometia esperança
e o navegador respondia com mais uma dor.

Vieram aliados, valentes companheiros,
justify-content, align-items, lado a lado,
mas muitos tombaram nos cantos da tela,
deixando o código ferido e desalinhado.

Tivemos fome — fome de um layout perfeito,
de um eixo que enfim pudesse obedecer,
mas cada margin: auto era uma trincheira,
cada position: absolute, medo de morrer.

Cruzamos vales de padding e margin,
sob chuva de pixels, sem saber onde ir,
e a cada tentativa perdida no caminho,
mais um companheiro deixava de existir.

float caiu primeiro, esquecido na história,
table-cell resistiu, mas não pôde avançar,
e o velho top: 50% gritou pela glória
antes de, cambaleante, também fracassar.

Até que, entre ruínas, surgiu a solução:
a div, finalmente, no centro do lugar.
Mas olhei para trás — e perguntei, em silêncio:
para que vencer, se tantos tiveram que tombar?

A div estava centralizada.
Mas a que custo?
